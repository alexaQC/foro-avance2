# Declaración de uso de inteligencia artificial

Utilicé ChatGPT como herramienta de apoyo durante el desarrollo de esta actividad.

## ¿En qué utilicé IA?

Usé IA principalmente para:

- Ayudarme a interpretar errores que aparecían al ejecutar comandos y el pipeline.
- Explicarme de forma más sencilla el hallazgo de seguridad detectado por Semgrep.
- Darme apoyo para corregir la vulnerabilidad XSS sin eliminar la funcionalidad de vista previa.

## ¿Qué hice personalmente?

Configuré la instancia de AWS, ejecuté los comandos, revisé los resultados del pipeline, comprobé que la aplicación funcionara, tomé las capturas para la evidencia y preparé los archivos/evidencias necesarios para la entrega final.


## Algo que tuve que corregir

La IA me sugirió eliminar la parte del código que estaba provocando que el pipeline bloqueara el despliegue, en el nuevo prompt especifiqué que se tenía que corregir la vulnerabilidad sin quitar la funcionalidad, después se ajustó la solución para arreglar el problema de XSS y mantener funcionando la vista previa.
